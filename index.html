🚀 Добро пожаловать в wordKnow

Это современный тренажер для эффективного заучивания терминов. Приложение создано, чтобы помочь вам легко и увлекательно освоить программирование, превратив скучную зубрежку в привычку.

🧠 Умный повтор Сложные слова попадаются чаще, а выученные отмечаются звёздочкой ★ (после 5 верных ответов подряд).
📚 Готовые словари В системе уже вшиты базовые наборы по HTML, CSS, SCSS, JavaScript и Svelte 5.

Возможности приложения

Интервальное повторение и адаптивность:

Приложение автоматически отслеживает сложный для вас материал. Если на вопрос дважды дан неверный ответ, слово получает статус сложного и начинает попадаться чаще. Слово считается полностью выученным после 5 правильных ответов подряд, после чего на карточке загорается особая звезда.

Словари:

Вы можете создавать, удалять и переключаться между несколькими независимыми словарями, управляя своей базой знаний прямо в Приложении.

Импорт и экспорт:

Поддерживается удобный обмен данными через JSON-файлы, что позволяет легко делиться наборами терминов или переносить их между устройствами.

Автоматическая стартовая база:

Приложение поставляется с уже готовыми глубокими словарями по HTML, CSS, SCSS, JavaScript и Svelte 5, которые автоматически подгружаются при первом запуске.

Чем приложение поможет новичку в программировании?

Для человека, который только начинает свой путь в IT, огромным барьером становится обилие специфической терминологии, названий тегов, атрибутов, свойств и синтаксических конструкций. AuraVocab решает эту проблему через игровую механику тестов с 4 вариантами ответов. Сеансы по 20 слов не перегружают внимание, а встроенная статистика успехов позволяет наглядно видеть глобальный прогресс (сколько всего терминов в базе и сколько из них уже успешно усвоено). Это превращает рутинную зубрежку в легкую ежедневную привычку, закладывая прочный фундамент для уверенной работы с кодом.
